Job Summary

ReliaQuest is hiring Associate Software Engineers to develop and enhance its GreyMatter cybersecurity platform. You will build scalable microservices, develop REST APIs, automate security workflows, participate in CI/CD pipelines, and collaborate with engineering teams to deliver innovative cloud-based security solutions.

Educational Qualification

  • B.E. / B.Tech / M.E. / M.Tech in Computer Science, IT or related field.
  • Eligible Batch: 2024 / 2025 / 2026.
  • 0–1 years of software development experience.
  • Freshers with strong programming skills are encouraged to apply.

Key Responsibilities

  • Develop frontend components using HTML, CSS, JavaScript and React.
  • Develop scalable applications using Java, Spring Boot and Microservices.
  • Build REST APIs and integrations for enterprise security platforms.
  • Develop automation for threat detection and response workflows.
  • Manage CI/CD pipelines for application deployment.
  • Perform code reviews and improve software quality.
  • Automate SDLC processes and engineering workflows.
  • Collaborate with cross-functional engineering teams.
  • Support teammates and contribute to an Agile development environment.

The everyday hustle

  • Research and develop creative solutions across a wide range of cutting-edge technologies to continuously evolve our platform, GreyMatter.
  • Create REST API’s and integrations between various products to improve and automate our customer’s threat detection.
  • Manage the continuous integration and deployment processes of complex technologies.
  • Perform code reviews to ensure consistent improvement.
  • Proactively automate and improve all stages of the software development lifecycle.
  • Interface closely with various parts of the business, both internally and externally, to ensure all users are leveraging the product with ease and to its full potential.
  • Provide support to other team members as well as cultivate a culture of constant collaboration.

Bonus Skills

  • Elasticsearch
  • Kafka

  • TensorFlow
  • Angular / React
  • AWS / Azure / GCP
  • Unit Testing
  • CI/CD Pipelines
  • Agile Methodology

Why Join ReliaQuest?

  • Work on cutting-edge cybersecurity products.
  • Build automation for global enterprise customers.
  • Learn from experienced software engineers.
  • Exposure to cloud-native technologies.
  • Career growth in security engineering.
  • Collaborative engineering culture.
  • Continuous learning and mentoring.
  • Global product development experience.

Additional Engineering Focus

  • Own AI-assisted article creation workflows from draft to publishing.
  • Enhance TipTap / ProseMirror rich-text editor capabilities.
  • Develop AI-powered editing, formatting and rewriting features.
  • Create reusable branded templates and content systems.
  • Build frontend-first full-stack product features.
  • Improve editor UX, workflows and interaction design.
